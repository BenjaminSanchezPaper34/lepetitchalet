# Le Petit Chalet — petitchalet.fr

Site du restaurant Le Petit Chalet (Pas de la Case, Andorre). Next.js 15 (App Router,
pages statiques régénérées chaque nuit), Tailwind 4, GSAP + Lenis. FR · ES · EN.
DA et règles : voir `DESIGN.md`.

- Contenus : `src/content/` (textes `i18n.ts`, carte `menu.ts`, identité et avis `site.ts`)
- Le bandeau « Ouverture le … » disparaît seul à la date `site.ouverture`
- `npm run dev` / `npm run build`

Réalisé par Paper34.
